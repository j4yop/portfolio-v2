## 🛠️ Complete Tech Stack

### Core Framework & Runtime
- **[Next.js 16](https://nextjs.org/):** App Router, Server Components, Route Handlers, Turbopack/Webpack compilation, and Production Static Site Generation (SSG).
- **[React 19](https://react.dev/):** Modern Concurrent features, Transitions, Suspense boundaries, and Hooks.
- **[TypeScript 5](https://www.typescriptlang.org/):** Strict type safety across domain models, component contracts, and API routes.
- **[Node.js 20+](https://nodejs.org/):** High-performance JavaScript runtime environment.

### Styling & Design System
- **[Tailwind CSS v4](https://tailwindcss.com/):** Next-generation CSS framework with zero-runtime CSS tokens and theme variables.
- **[next-themes](https://github.com/pacocoursey/next-themes):** Seamless, flicker-free dark & light mode synchronization with system preferences.
- **Blueprint UI Theme:** Custom Swiss-inspired architectural grid lines, dashed crosshairs, ultra-fine coordinate intersection nodes, and monospace metadata badges.

### Graphics, Shaders & Animation
- **[Three.js](https://threejs.org/):** WebGL-powered interactive displacement typography canvas with custom GLSL vertex shaders (`JAY GOPAL`).
- **[Framer Motion](https://www.framer.com/motion/):** Physics-based layout transitions, hover cards, staggered lists, and smooth tab animations.
- **[GSAP (GreenSock)](https://greensock.com/gsap/):** ScrollTrigger sequences, precision timeline coordination, and micro-motion.
- **HTML5 Canvas:** Interactive particle physics simulation and mouse-following velocity vectors.

### Component Libraries & Primitives
- **[shadcn/ui](https://ui.shadcn.com/):** High-quality, composable accessible components.
- **[Radix UI](https://www.radix-ui.com/):** Unstyled accessible primitives (Dialog, Popover, Hover Card, Separator, Tooltip).
- **[cmdk](https://cmdk.paco.me/):** Fast, extensible command menu palette (`Cmd + K` / `Ctrl + K`).
- **[Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/):** Multi-set iconography (Lucide, Simple Icons, FontAwesome).

### Gamification & Micro-Interactions
- **Oneko Animated Cursor Companion:** Retro 8-directional animated pet inspired by classic desktop companions that chases the cursor, enters idle scratch/sleep states, and responds to click interactions.

### Telemetry, APIs & Cloud Deployment
- **GitHub GraphQL & REST API:** Live telemetry pipeline with server-side caching and multi-tier calendar fallback for activity heatmaps.
- **Formspree:** Production-grade encrypted contact form endpoint routing directly to inbox.
- **[Vercel Platform](https://vercel.com/):** Edge network CDN, automatic HTTPS, global edge routing, Vercel Web Analytics, and Speed Insights monitoring.

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/j4yop/portfolio-v2.git
cd portfolio-v2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables (optional)
Create a `.env.local` file in the root directory:
```env
# Optional: Higher rate limits for live GitHub telemetry
GITHUB_TOKEN=your_github_personal_access_token
```

### 4. Start the local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production build
```bash
npm run build
npm run start
```
